# Telegram-бот и Mini App для турниров по настольному теннису

Приложение регистрирует игроков, создаёт турнирные сетки, показывает их в
адаптивном Telegram Mini App и автоматически продвигает победителей.

Поддерживаются форматы:

- **Single Elimination** — игрок выбывает после первого поражения;
- **Double Elimination** — игрок переходит в нижнюю сетку и выбывает после
  второго поражения;
- **Круговой турнир** — каждый играет с каждым, места считаются по победам.
  При равенстве двух лидеров учитывается личная встреча, при сложном равенстве —
  начальный порядок участников.

Возможности:

- регистрация через `/start` или при открытии Mini App;
- выбор зарегистрированных игроков и добавление гостей вручную;
- управление составом и результатами только администратором турнира;
- красивая интерактивная сетка, таблица и расписание;
- автоматические пропуски раунда и финальная серия Double Elimination;
- подтверждение победителя касанием по карточке матча;
- SQLite и сохранение данных после перезапуска;
- проверка подписи `Telegram.WebApp.initData` на сервере.

## Локальный запуск

Запускайте команды из корневой папки проекта:

```powershell
cd C:\Users\inost\Documents\TableTennis
```

Нужен Python 3.10 или новее.

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
Copy-Item .env.example .env
```

Откройте `.env` и укажите токен от [@BotFather](https://t.me/BotFather):

```dotenv
BOT_TOKEN=токен_от_BotFather
ADMIN_IDS=
DATABASE_PATH=data/table_tennis.sqlite3
MAX_PLAYERS=32
MINIAPP_URL=
WEB_HOST=127.0.0.1
WEB_PORT=8080
WEBAPP_DEV_MODE=0
```

Запуск:

```powershell
.\.venv\Scripts\python.exe -m table_tennis_bot.main
```

Бот и веб-сервер запускаются одним процессом. Локальный адрес Mini App:
`http://127.0.0.1:8080`.

## Локальная проверка Mini App в браузере

Telegram передаёт данные пользователя только внутри своего WebView. Для
локальной разработки временно включите:

```dotenv
WEBAPP_DEV_MODE=1
```

После перезапуска откройте `http://127.0.0.1:8080`. На публичном сервере
обязательно верните `WEBAPP_DEV_MODE=0`.

## Подключение Mini App к Telegram

Telegram открывает Mini App только по публичному **HTTPS**-адресу. Разместите
проект на сервере с постоянным диском для SQLite или запустите HTTPS-туннель,
затем задайте:

```dotenv
MINIAPP_URL=https://your-domain.example
WEB_HOST=0.0.0.0
WEB_PORT=8080
WEBAPP_DEV_MODE=0
```

После перезапуска бот автоматически:

- добавит команду `/app`;
- покажет кнопку «Открыть Mini App»;
- установит Mini App как кнопку меню чата.

Для большой кнопки **Launch app** в профиле бота дополнительно настройте
`@BotFather` → Bot Settings → Configure Mini App и укажите тот же URL.

## Права администратора

Создатель турнира управляет его составом и результатами. Глобальных
администраторов можно указать через запятую:

```dotenv
ADMIN_IDS=123456789,987654321
```

## Docker

В проекте есть готовый `Dockerfile`. При размещении обязательно:

- передайте `BOT_TOKEN`, `MINIAPP_URL` и остальные настройки как переменные
  окружения;
- подключите постоянный том к `/data`;
- направьте HTTPS-трафик на порт `8080`.

Проверить состояние сервера можно через `GET /api/health`.

## Тесты

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

Тесты проверяют все три формата, продвижение игроков, таблицу, API Mini App и
криптографическую проверку данных Telegram.
